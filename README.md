# deed.page plugin marketplace

This repository folder holds the deed.page plugin for Claude (`./claude-plugin`), version 1.19.0. The plugin connects Claude to the hosted deed.page MCP server at https://deed.page/mcp/claude and adds the `publish-with-deed-page` skill, so Claude can publish static files to a permanent HTTPS URL. See `claude-plugin/README.md` for what it runs and sends. Operated by Avatar 8 LLC. Support: ops@avatar33.com.
